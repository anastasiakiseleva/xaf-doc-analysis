# Create Additional ListView Nodes in Code Using a Generator Updater

By default, two ListView nodes are generated in the [Application Model](xref:112579) for each business class. These nodes represent a general-purpose List View, and a Lookup List View that contains fewer columns (see [List View Column Generation](xref:113285)). Often, it is required to add more List Views manually. These additional List Views can be used as [View Variants](xref:113011), [Dashboard](xref:113296) items, etc. Typically, this task can be accomplished in the [Model Editor](xref:112582). However, in certain scenarios, adding nodes in code may be required. 

The default process of generating **Views** node's child nodes is handled by the built-in [](xref:DevExpress.ExpressApp.Model.NodeGenerators.ModelViewsNodesGenerator) Nodes Generator. To customize this process, you should "attach" a Generator Updater class to this Generator. This topic describes how to implement a Generator Updater that creates custom ListView nodes. Additionally, an Updater that creates View Variants using these new nodes is illustrated. For details on Nodes Generators and Generator Updaters, refer to the [Extend and Customize the Application Model in Code](xref:112810) topic.

## Create List Views

This List View is defined by the **Views** | **Employee_ListView** node. Let us implement a Generator Updater that generates two additional List Views, which are:

1. A List View with hidden **FirstName** and **LastName** columns (**Employee_ListView_FewColumns**);
2. A List View where records are grouped by the **Position** column (**Employee_ListView_Grouped**).

A Generator Updater class should inherit the abstract [](xref:DevExpress.ExpressApp.Model.ModelNodesGeneratorUpdater`1) class, where **T** is the type of the Nodes Generator to be customized. A built-in Nodes Generator that generates the **Views** node content is the **ModelViewsNodesGenerator**. The abstract [ModelNodesGeneratorUpdater`1.UpdateNode](xref:DevExpress.ExpressApp.Model.ModelNodesGeneratorUpdater`1.UpdateNode(DevExpress.ExpressApp.Model.Core.ModelNode)) method must be implemented in a custom Generator Updater. The parameter of the **ModelNode** type, passed to this method, represents a generated node. In our case, this node is the Views node. To add child nodes, the **ModelNode.AddNode\<T>** method can be used. Note that the [IModelObjectView.ModelClass](xref:DevExpress.ExpressApp.Model.IModelObjectView.ModelClass) property must be specified for each **ListView** node. After that, the **ListView** node properties can be accessed and their values can be customized. To access the **Columns** node, use the [IModelListView.Columns](xref:DevExpress.ExpressApp.Model.IModelListView.Columns) property. The following snippet illustrates the **AddListViewNodesGeneratorUpdater** Generator Updater class.

# [C#](#tab/tabid-csharp)

```csharp
using DevExpress.ExpressApp.Model;
using DevExpress.ExpressApp.Model.Core;
using DevExpress.ExpressApp.Model.NodeGenerators;
// ...
public class AddListViewNodesGeneratorUpdater : 
    ModelNodesGeneratorUpdater<ModelViewsNodesGenerator> {
    public const string FewColumnsListViewNodeIdSuffix = "_FewColumns";
    string[] columnsToHideIds = { "FirstName", "LastName" };
    public const string GroupedListViewNodeIdSuffix = "_Grouped";
    public const string GroupByColumnId = "Position";
    static Type targetType = typeof(Employee);
    public override void UpdateNode(ModelNode viewsNode) {
        AddFewColumnsListViewNode(viewsNode);
        AddGroupedListViewNode(viewsNode);
    }
    public static IModelListView GetDefaultListView(ModelNode viewsNode) {
        return viewsNode.Application.BOModel.GetClass(targetType).DefaultListView;
    }
    IModelListView AddListViewNode(ModelNode viewsNode, string listViewId) {
        IModelListView listViewNode = (IModelListView)viewsNode.AddNode<IModelListView>(listViewId);
        listViewNode.ModelClass = viewsNode.Application.BOModel.GetClass(targetType);
        return listViewNode;
    }
    void AddFewColumnsListViewNode(ModelNode viewsNode) {
        string nodeId = GetDefaultListView(viewsNode).Id + FewColumnsListViewNodeIdSuffix;
        IModelListView fewColumnsListViewNode = AddListViewNode(viewsNode, nodeId);
        IModelColumns columns = (IModelColumns)fewColumnsListViewNode.Columns;
        foreach (string columnId in columnsToHideIds) {
            columns[columnId].Index = -1;
        }
    }
    void AddGroupedListViewNode(ModelNode viewsNode) {
        string nodeId = GetDefaultListView(viewsNode).Id + GroupedListViewNodeIdSuffix;
        IModelListView groupedListViewNode =
            AddListViewNode(viewsNode, nodeId);
        IModelColumns columns = (IModelColumns)groupedListViewNode.Columns;
        columns[GroupByColumnId].GroupIndex = 1;
    }
}
```

# [VB.NET](#tab/tabid-vb)

```vb
Imports DevExpress.ExpressApp.Model;
Imports DevExpress.ExpressApp.Model.Core;
Imports DevExpress.ExpressApp.Model.NodeGenerators;
' ...
Public Class AddListViewNodesGeneratorUpdater
    Inherits ModelNodesGeneratorUpdater(Of ModelViewsNodesGenerator)
    Public Const FewColumnsListViewNodeIdSuffix As String = "_FewColumns"
    Private columnsToHideIds() As String = { "FirstName", "LastName" }
    Public Const GroupedListViewNodeIdSuffix As String = "_Grouped"
    Public Const GroupByColumnId As String = "Position"
    Private Shared targetType As Type = GetType(Employee)
    Public Overrides Sub UpdateNode(ByVal viewsNode As ModelNode)
        AddFewColumnsListViewNode(viewsNode)
        AddGroupedListViewNode(viewsNode)
    End Sub
    Public Shared Function GetDefaultListView(ByVal viewsNode As ModelNode) As IModelListView
        Return viewsNode.Application.BOModel.GetClass(targetType).DefaultListView
    End Function
    Private Function AddListViewNode(ByVal viewsNode As ModelNode, ByVal listViewId As String) _
    As IModelListView
        Dim listViewNode As IModelListView = _
        CType(viewsNode.AddNode(Of IModelListView)(listViewId), IModelListView)
        listViewNode.ModelClass = viewsNode.Application.BOModel.GetClass(targetType)
        Return listViewNode
    End Function
    Private Sub AddFewColumnsListViewNode(ByVal viewsNode As ModelNode)
        Dim nodeId As String = GetDefaultListView(viewsNode).Id & FewColumnsListViewNodeIdSuffix
        Dim fewColumnsListViewNode As IModelListView = AddListViewNode(viewsNode, nodeId)
        Dim columns As IModelColumns = CType(fewColumnsListViewNode.Columns, IModelColumns)
        For Each columnId As String In columnsToHideIds
            columns.GetNode(columnId).Index = -1
        Next columnId
    End Sub
    Private Sub AddGroupedListViewNode(ByVal viewsNode As ModelNode)
        Dim nodeId As String = GetDefaultListView(viewsNode).Id & GroupedListViewNodeIdSuffix
        Dim groupedListViewNode As IModelListView = AddListViewNode(viewsNode, nodeId)
        Dim columns As IModelColumns = CType(groupedListViewNode.Columns, IModelColumns)
        CType(columns.GetNode(GroupByColumnId), IModelColumn).GroupIndex = 1
    End Sub
End Class
```

***

You can place this class in a separate code file in the [module project](xref:118045), or add it to the _Module.cs_ file. The implemented Generator Updater should be registered in the overridden [ModuleBase.AddGeneratorUpdaters](xref:DevExpress.ExpressApp.ModuleBase.AddGeneratorUpdaters(DevExpress.ExpressApp.Model.Core.ModelNodesGeneratorUpdaters)) method in the following manner:

# [C#](#tab/tabid-csharp)

```csharp
using DevExpress.ExpressApp.Model.Core;
// ...
public sealed partial class CreateNodesInCodeModule : ModuleBase {
    // ...
    public override void AddGeneratorUpdaters(ModelNodesGeneratorUpdaters updaters) {
        base.AddGeneratorUpdaters(updaters);
        updaters.Add(new AddListViewNodesGeneratorUpdater());
    }
}
```

# [VB.NET](#tab/tabid-vb)

```vb
Imports DevExpress.ExpressApp.Model.Core
' ...
Public NotInheritable Partial Class CreateNodesInCodeModule
    Inherits ModuleBase
    ' ...
    Public Overrides Sub AddGeneratorUpdaters(ByVal updaters As ModelNodesGeneratorUpdaters)
        MyBase.AddGeneratorUpdaters(updaters)
        updaters.Add(New AddListViewNodesGeneratorUpdater())
    End Sub
End Class
```

## Create View Variants
Let us implement View Variants for Employee List View to make List Views created in the previous section of this topic visible in the UI. Although the View Variants are typically designed in the Model editor, it is also possible to create View Variants in code, via the Generator Updater. The Generator Updater that generates View Variants using Views created by the **AddListViewNodesGeneratorUpdater** is illustrated in the snippet below. The View Variants module should be added before implementing this class.

# [C#](#tab/tabid-csharp)

```csharp
using DevExpress.ExpressApp.Model;
using DevExpress.ExpressApp.Model.Core;
using DevExpress.ExpressApp.Model.NodeGenerators;
using DevExpress.ExpressApp.ViewVariantsModule;
// ...
class AddViewVariantsGeneratorUpdater : ModelNodesGeneratorUpdater<ModelViewsNodesGenerator> {
    public override void UpdateNode(ModelNode viewsNode) {
        IModelView rootView = AddListViewNodesGeneratorUpdater.GetDefaultListView(viewsNode);
        IModelView fewColumnsListView = 
            (IModelView)viewsNode.GetNode(rootView.Id +
            AddListViewNodesGeneratorUpdater.FewColumnsListViewNodeIdSuffix);
        IModelView groupedListView =
            (IModelView)viewsNode.GetNode(rootView.Id +
            AddListViewNodesGeneratorUpdater.GroupedListViewNodeIdSuffix);
        AddVariant("Default", "Default", rootView, rootView, true);
        AddVariant("FewColumns", "Few Columns", rootView, fewColumnsListView, false);
        AddVariant("Grouped", "Grouped", rootView, groupedListView, false);
    }
    void AddVariant(string variantId, string caption, 
        IModelView rootView, IModelView variantView, bool isCurrent) {
        IModelVariants variants = ((IModelViewVariants)rootView).Variants;
        IModelVariant variant = variants.AddNode<IModelVariant>(variantId);
        variant.View = variantView;
        variant.Caption = caption;
        if (isCurrent) variants.Current = variant;
    }
}
```

# [VB.NET](#tab/tabid-vb)

```vb
Imports DevExpress.ExpressApp.Model
Imports DevExpress.ExpressApp.Model.Core
Imports DevExpress.ExpressApp.Model.NodeGenerators
Imports DevExpress.ExpressApp.ViewVariantsModule
' ...
Friend Class AddViewVariantsGeneratorUpdater
    Inherits ModelNodesGeneratorUpdater(Of ModelViewsNodesGenerator)
    Public Overrides Sub UpdateNode(ByVal viewsNode As ModelNode)
        Dim rootView As IModelView = AddListViewNodesGeneratorUpdater.GetDefaultListView(viewsNode)
        Dim fewColumnsListView As IModelView = _
        CType(viewsNode.GetNode(rootView.Id + _
        AddListViewNodesGeneratorUpdater.FewColumnsListViewNodeIdSuffix), IModelView)
        Dim groupedListView As IModelView = _
        CType(viewsNode.GetNode(rootView.Id + _
        AddListViewNodesGeneratorUpdater.GroupedListViewNodeIdSuffix), IModelView)
        AddVariant("Default", "Default", rootView, rootView, True)
        AddVariant("FewColumns", "Few Columns", rootView, fewColumnsListView, False)
        AddVariant("Grouped", "Grouped", rootView, groupedListView, False)
    End Sub
    Private Sub AddVariant(ByVal variantId As String, ByVal caption As String, _
    ByVal rootView As IModelView, ByVal variantView As IModelView, ByVal isCurrent As Boolean)
        Dim variants As IModelVariants = (CType(rootView, IModelViewVariants)).Variants
        Dim [variant] As IModelVariant = variants.AddNode(Of IModelVariant)(variantId)
        [variant].View = variantView
        [variant].Caption = caption
        If isCurrent Then
            variants.Current = [variant]
        End If
    End Sub
End Class
```
